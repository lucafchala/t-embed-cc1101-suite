# koua29 — temas visuais para Bruce (LilyGO T-Embed CC1101)

Dois conjuntos de temas de UI feitos especificamente para a tela 320×170
do T-Embed CC1101.

- **`Amber HUD/`, `Blue HUD/`, `White HUD/`** — tema "HUD de
  instrumento": cada item do menu mostra um ícone técnico (Material
  icons) sobre fundo estilo blueprint, com leve animação de varredura de
  luz. Três variações de cor (âmbar, azul, branco).
- **`Wheel_Light/`, `Wheel_Dark/`** — tema "roda radial": todos os ícones
  do menu aparecem numa roda à esquerda (o atual em destaque por
  inversão), nome do item em fonte grande (Anton) à direita, fundo
  monocromático. Claro (roda preta/fundo branco) e escuro (roda
  branca/fundo preto).
- **`tools/wheel_theme.py`** — script gerador usado para produzir os
  assets do tema "roda radial" a partir de um conjunto de ícones fonte;
  incluído para quem quiser adaptar as cores/ícones.

## Uso

Copie a pasta do tema desejado para o cartão SD e selecione em
`Config → UI Theme` no Bruce.
