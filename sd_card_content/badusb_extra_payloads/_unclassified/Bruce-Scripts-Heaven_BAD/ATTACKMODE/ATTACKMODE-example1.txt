REM [Bruce compat rewrite] Original Hak5 ATTACKMODE demo re-enumerated the
REM device between HID keyboard / mass storage / composite modes. Bruce's
REM ducky_typer.cpp has no ATTACKMODE support — it is always a fixed HID
REM keyboard, so every ATTACKMODE line below was removed. Only the narration
REM strings and delays are left, typed as a straight sequence.
REM The ATTACKMODE command may be used multiple times throughout a payload.
REM Changing the attack mode will cause the target to re-enumerate the device.
DELAY 2000
STRING The USB Rubber Ducky is functioning as a keyboard.
ENTER
STRING It will function as a flash drive for the next 30 seconds.
ENTER
DELAY 30000
DELAY 2000
STRING Now the USB Rubber Ducky is back to functioning as only a keyboard.
ENTER
STRING For the next 30 seconds it will function as both keyboard and storage.
ENTER
DELAY 30000
STRING Now the USB Rubber Ducky will disable itself.
ENTER
REM This payload will begin by enumerating as a HID keyboard.
REM The USB Rubber Ducky will then enumerate as a mass storage "flash drive" for 30 seconds.
REM Once more it will be enumerated as only a HID keyboard.
REM Next it will enumerate as both a HID keyboard and a mass storage "flash drive".
