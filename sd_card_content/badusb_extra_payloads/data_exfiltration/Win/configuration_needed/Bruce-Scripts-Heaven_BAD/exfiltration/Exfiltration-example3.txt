REM the core technique depends on the USB Rubber Ducky's own firmware
REM capability to read HID-OUT keyboard-LED reports back from the host

REM writing new firmware-level capability from scratch, not converting
REM syntax (same situation as the EXTENSION-dependent files, see
REM depende_de_extension/README.md).
REM What IS kept below: the two PowerShell one-liners that dump the
REM Wi-Fi profile key and re-encode it into %{CAPSLOCK}/%{NUMLOCK}

REM SendKeys playback (the actual reflection back to the Ducky) has no
